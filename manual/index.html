User Manual & Documentation

Windows Maintenance Tool

A comprehensive system helper that automates cleaning temporary files, monitoring system health, checking for outdated drivers, and performing essential maintenance routines.

  • How to use: Run as Administrator, then click "Start Maintenance" to begin automated cleanup.
  • Features: Disk cleanup, SFC scan, DISM repair, driver check.

Windows Optimizer

Unlock maximum system performance by disabling unnecessary background services, adjusting system settings, and applying intelligent performance tweaks.

  • How to use: Launch the app, select which optimizations to apply, and click "Apply Changes".
  • Features: Visual effects, background apps, search indexing, backup & restore.

DNS Manager

Effortlessly test and apply the fastest DNS servers, enhance your internet speed, and monitor DNS response times.

  • How to use: Click "Scan" to find fastest DNS, then "Apply" to set it.
  • Features: DNS benchmarking, multiple provider support, one-click switching.

Winget Tool

A user-friendly GUI for Microsoft Winget, allowing seamless searching, installation, and updates of software packages.

  • How to use: Click "Scan Updates" to check for available updates, select packages, click "Update Selected".
  • Features: GUI interface, progress tracking, dark theme.

Dockers

An elegant PyQt6-based dock that lets you pin, organize, and launch applications quickly.

  • How to use: Launch the app, right-click to add folders, press Ctrl+Shift+L to toggle visibility.
  • Features: Auto-hide, custom icons, transparency control.
  • ✅ Short-cut key: Ctrl + Shift + L for lock and unlock the Dockers

Windows Debloater & Privacy

Optimize performance and privacy through bloatware removal, telemetry disabling, and resource optimization.

  • How to use: Run as Administrator, select items to remove, click "Debloat".
  • Features: Bloatware removal, telemetry disable, restore center.

Windows Security Manager

One-click control over eight security features including Defender, Firewall, BitLocker, and more.

  • How to use: Toggle switches to enable/disable security features, click "Apply".
  • Features: Real-time monitoring, PowerShell integration, backups.

Math Challenge Pro Game

Interactive educational game for ages 7-12, transforming math practice into a high-stakes competition.

  • How to use: Select difficulty level, start game, answer math questions quickly.
  • Features: Adaptive levels, real-time scoring, local leaderboard.

General Usage Tips

  • ✅ Always run system tools as Administrator for full functionality.
  • ✅ Create a system restore point before making major changes.
  • ✅ Check the FAQ page if you encounter any issues.
